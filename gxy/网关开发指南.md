# 网关开发指南

## 项目概述
使用纯 Go 语言开发的轻量级 API 网关，不依赖任何第三方框架，实现服务注册发现、负载均衡、健康检查和集群数据同步功能。

## 核心功能

### 1. 服务注册与发现
- 服务实例启动时自动向网关注册服务地址
- 支持同一服务的多个实例注册
- 网关维护服务注册列表

### 2. 负载均衡
- 采用轮询（Round Robin）算法分发请求
- 结合最少连接优先策略
- 网关接收客户端请求并转发到后端服务

### 3. 健康检查
- 定时检查注册服务的健康状态
- 自动剔除不健康的服务实例
- 并发健康检查，支持可配置的并发限制

### 4. 网关集群
- 无主模式部署多个网关实例
- 网关间自动同步服务注册数据
- 故障网关自动从集群中剔除

### 核心组件

#### 服务注册中心 (Registry)
- 使用 map 存储服务名称到服务实例列表的映射
- 维护实例 ID 到实例的直接映射，支持 O(1) 查找
- 线程安全设计（使用 sync.RWMutex 保护共享数据）

#### 健康检查 (Health Checker)
- 定期发送 HTTP 请求检查服务健康
- 支持可配置的检查间隔和超时时间
- 使用复用的 HTTP 客户端减少资源消耗

#### 负载均衡 (Round Robin)
- 轮询算法选择服务实例
- 考虑服务健康状态和连接数
- 使用读写锁减少锁竞争

#### 网关集群同步
- 使用 HTTP 实现网关间通信
- 采用种子节点发现机制
- 节点心跳检测，自动剔除故障节点

#### 请求代理转发
- 实现 HTTP 请求的接收和转发
- 处理请求头、请求体的转发
- 优化 HTTP 连接池配置

## 网络通信协议

### 服务注册协议
```
POST /register
Content-Type: application/json
Authorization: Bearer your-registration-secret-key

{
    "id": "service-instance-1",
    "name": "user-service",
    "address": "192.168.1.100",
    "port": 8080,
    "metadata": {
        "version": "1.0.0",
        "health_path": "/health"
    }
}
```

### 集群同步接口

| 接口 | 方法 | 说明 |
|------|------|------|
| `/node/register` | POST | 注册新节点 |
| `/node/info` | GET | 获取节点信息 |
| `/node/list` | GET | 获取集群节点列表 |
| `/sync` | POST | 集群数据同步 |

| 配置项 | 说明 |
|--------|------|
| listen_addr | 网关监听地址 |
| listen_port | 网关监听端口 |
| register_ttl | 服务注册过期时间 |
| health_check_interval | 健康检查间隔 |
| health_check_timeout | 健康检查超时 |
| seed_nodes | 种子节点列表 |
| heartbeat_interval | 心跳间隔 |
| register_auth_key | 服务注册认证密钥 |
| enable_auto_discovery | 是否启用自动发现 |
| node_discovery_port | 节点发现服务端口 |

## 开发部署流程

### 1. 本地交叉编译
修改代码后，先编译为 Linux 可执行文件：
```bash
cd gxy
$env:CGO_ENABLED='0'; $env:GOOS='linux'; $env:GOARCH='amd64'
go build -o ./cmd/build/gateway ./cmd/gateway
```

### 2. 重新构建并启动容器
```bash
docker compose -f docker-compose-gxy.yml up -d --build
```


## 日志说明

### 日志级别
- DEBUG：调试信息
- INFO：运行信息
- WARN：警告信息
- ERROR：错误信息
- FATAL：致命错误

### 日志位置
- 本地运行：输出到终端，可通过 `-log` 参数指定日志文件
- Docker 运行：同时输出到终端和文件

### 日志文件
- 路径：`run/gxy/logs/gateway-YYYY-MM-DD.log`
- 按天自动分割，每天一个文件
- 查看日志：`docker logs gxy-gateway`
- 实时跟踪：`docker logs -f gxy-gateway`

### 日志参数
```bash

go run cmd/gateway/main.go -config config.json -log ./logs/gateway.log
```

## 部署与运维

### 多网关统一入口

#### Nginx 负载均衡
```nginx
http {
  upstream gateway_cluster {
    server gateway1:8585;
    server gateway2:8585;
    server gateway3:8585;
  }

  server {
    listen 80;

    location / {
      proxy_pass http://gateway_cluster;
      proxy_set_header Host $host;
      proxy_set_header X-Real-IP $remote_addr;
      proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    }
  }
}
```

## 技术要点

1. **纯 Go 实现**：不依赖第三方框架，充分利用 Go 标准库
2. **并发安全**：使用 sync 包确保线程安全
3. **高性能**：利用 Go 的并发特性处理高并发请求
4. **可靠性**：完善的错误处理和故障转移机制
5. **可扩展性**：模块化设计，便于功能扩展
6. **易维护**：清晰的代码结构和详细的文档
